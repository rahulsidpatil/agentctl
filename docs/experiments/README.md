# Experiments

Experiments turn material uncertainty into evidence. Create a GitHub issue with
`type:experiment`, copy the template below into a record when the experiment is
complete, and link the issue, branch, pull request, tests, and sanitized output.

Results are `Validated`, `Partially validated`, or `Invalidated`. An invalidated
hypothesis is a useful result, not a failed contribution.

Initial MVP experiments cover all six directed provider handoffs, token
exhaustion, process crash, terminal interruption, invalid checkpoint recovery,
clean installation, and each Tier 1 platform.
