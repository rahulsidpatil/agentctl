# AI-native SDLC principles

1. **Humans own outcomes.** Agents may implement work, but maintainers remain
   accountable for scope, safety, review, and release.
2. **Evidence over confidence.** Tests, reproducible commands, and observed
   results support claims of readiness.
3. **Durable context over session memory.** Objectives, decisions, validation,
   and remaining work survive individual agent sessions.
4. **Safety before automation.** Automation must preserve user work and expose
   consequential actions.
5. **Test-first change.** Behavior begins as a failing test and ends with
   regression evidence.
6. **Provider and platform neutrality.** Shared contracts contain variation at
   explicit boundaries.
7. **Learn in public.** Achievements, misses, invalid assumptions, and follow-up
   actions are recorded without hiding inconvenient results.
8. **Promote only validated practices.** A project observation becomes a
   reusable framework rule only after evidence and a second-project pilot.
