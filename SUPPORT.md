# Support

`agentctl` is alpha software maintained on a best-effort basis.

- Use a GitHub bug report for reproducible defects.
- Use a platform-support report for macOS, Ubuntu, Windows, or WSL problems.
- Use a provider-integration report for Codex, Claude, or Antigravity behavior.
- Use GitHub Discussions for usage questions once Discussions are enabled.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities or credential
  exposure; do not open a public issue for those reports.

Include `agentctl --version`, the operating system, provider version, sanitized
`agentctl doctor` output, reproduction steps, and expected versus actual
behavior. Remove credentials, private paths, source content, and session data
that is not necessary to reproduce the problem.
